# Product boundary

The repository bootstrap is an open/local capability. It generates customer-owned configuration and a GitHub Actions workflow but does not require Tooensure Cloud.

A future Tooensure hosted control plane may trigger `repository_dispatch`, supply hosted runner/model capacity, retain validated-resource registries, run federation/evaluation services, provide enterprise governance, or offer support. Those are separately metered managed services.

Budget, account tier, or willingness to pay may change quotas and scheduling priority, but never grants a capability, bypasses governance, or changes checker independence.
